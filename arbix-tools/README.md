# ARBI X TEAM · Tools

Міні-застосунок для учнів: P2P-сканер (Binance, OKX, Bybit), калькулятор зв'язки, тести по 10 етапах, чекліст «перед тим як відпустити USDT», шаблони повідомлень, глосарій. Плюс бот, який нагадує про уроки в групі.

Подивитись без деплою: відкрий `index.html` через будь-який локальний сервер і додай `?demo=1`, тоді сканер покаже демо-дані.

---

## 1. Деплой на Vercel (5 хвилин)

1. Зайди на github.com → **New repository** → назва `arbix-tools` → Create.
2. На сторінці репозиторію: **Add file → Upload files** → перетягни ВСІ файли й папки з цього архіву (index.html, assets, api, lib, schedule.json, vercel.json, package.json) → **Commit**.
3. Зайди на vercel.com → увійди через GitHub → **Add New → Project** → обери `arbix-tools` → **Deploy**. Нічого не налаштовуй, збірка не потрібна.
4. Отримаєш посилання на кшталт `https://arbix-tools.vercel.app`. Відкрий його й натисни «Сканувати».

> Якщо якась біржа показує «помилка», вона тимчасово блокує запити з серверів Vercel. Зазвичай це минає за кілька хвилин. Якщо помилка тримається довго, напиши мені: підлаштую запит.

## 2. Кнопка застосунку в Telegram (Mini App)

1. Відкрий @BotFather → `/newbot` → назви бота, наприклад `ARBI X Tools`, і отримай **токен** (він знадобиться і для нагадувань).
2. У @BotFather: `/mybots` → твій бот → **Bot Settings → Menu Button** → встав посилання з Vercel → назва кнопки `Інструменти`.
3. Тепер у бота є кнопка, яка відкриває застосунок прямо в Telegram. Посилання на бота закріпи в гілці «🧰 Інструменти».

## 3. Бот-нагадування про уроки

1. Додай бота в групу «ARBI X TEAM · Навчання P2P | Базовий» і зроби його **адміном** з правом надсилати повідомлення.
2. Vercel → проєкт → **Settings → Environment Variables**, додай:
   - `BOT_TOKEN` — токен з @BotFather
   - `CHAT_ID` — `-1004356545590` (ID твоєї групи)
   - `CRON_SECRET` — будь-який довгий випадковий рядок (наприклад, 30 літер і цифр)
3. **Deployments → Redeploy**, щоб змінні підтягнулись.
4. Перевір: відкрий `https://<твій-домен>/api/remind?test=1&key=<CRON_SECRET>`. У гілці «📢 Оголошення» має з'явитись тестове повідомлення.
5. Відкрий `schedule.json` на GitHub (олівець → редагувати) і впиши дати уроків у форматі `"date": "2026-11-20"`. Commit, і Vercel сам оновить сайт.

Бот запускається щодня о 10:00 за Києвом (взимку). За день до уроку пише «⏰ Завтра о 21:00…», у день уроку пише «🔥 Сьогодні о 21:00…». Усе йде в гілку «📢 Оголошення».

## 5. Бот підтримки учнів

Учні пишуть боту в особисті повідомлення, кожне питання (зі скрінами) падає в закриту групу кураторів. Куратор натискає «Відповісти» на повідомлення учня, і бот сам доставляє відповідь учню. Кнопка «✅ Вирішено» закриває питання і повідомляє учня.

1. Створи в Telegram закриту групу, наприклад «ARBI · Підтримка», і додай туди кураторів.
2. Додай у неї свого бота і зроби його адміном.
3. Напиши в цій групі `/chatid`, бот відповість числом. Це `SUPPORT_CHAT_ID`.
4. Vercel → Settings → Environment Variables → додай `SUPPORT_CHAT_ID` (і `BOT_TOKEN` та `CRON_SECRET`, якщо їх ще немає) → Redeploy.
5. Один раз відкрий `https://<твій-домен>/api/support?setup=1&key=<CRON_SECRET>`. Має бути `"ok": true`.
6. Напиши боту `/start` зі свого акаунта і перевір, що повідомлення дійшло в групу кураторів.

**Доступ тільки для учнів.** Бот пускає до кураторів тільки тих, хто зараз є в групі навчання (ARBI SCHOOL). Усі інші отримують «🔒 немає доступу» і кнопку «Написати менеджеру». Щоб це працювало:
- додай бота в групу ARBI SCHOOL і зроби адміном (права можна дати мінімальні);
- у `support.json` заміни `@your_manager` на нік менеджера;
- якщо група навчання інша, додай у Vercel змінну `STUDENTS_CHAT_ID` з її ID (за замовчуванням -1004356545590).

Тексти привітання, автовідповіді та кнопок FAQ редагуються в `support.json`.

## 4. Що де редагувати

- `assets/data.js`: питання тестів, глосарій, шаблони, чекліст, список банків.
- `lib/banks.js`: ідентифікатори банків на кожній біржі (якщо біржа перейменує банк).
- `schedule.json`: розклад уроків для бота.

## Важливо

- Дані сканера беруться з публічних P2P-маркетів бірж через їхні неофіційні ендпоінти. Біржа може змінити формат, тоді сканер треба підлатати.
- Ціни можуть відставати на 20–60 секунд. Перед угодою завжди перевіряй ціну на самій біржі.
- Між біржами сканер не враховує комісію мережі за переказ.

## Оновлення: ДЗ, тренажер, іспит, умови

### Домашні завдання (бот підтримки)
- Учень пише боту `/dz` → бачить 10 завдань (по одному на етап).
- Здає: скрін/файл з підписом `/dz 3` або текстом `/dz 3 мій план…`.
- У групі кураторів зʼявляється ДЗ з кнопками **✅ Зараховано** / **🔁 Доробити**. Учню приходить результат.
- Коментар учню: відповідай реплаєм на повідомлення з ДЗ (як і на звичайні питання).
- Тексти завдань — у `support.json` → `homework`. Редагуй як хочеш.
- Після деплою один раз відкрий `/api/support?setup=1&key=<CRON_SECRET>`, щоб у меню бота зʼявилась команда /dz.

### Тренажер ситуацій
Вкладка 🎯 у Mini App. 20 кейсів, тексти — `assets/data.js` → `ARBI.CASES`.

### Фінальний іспит і сертифікат
- Вкладка 🎓. 30 питань (3 на етап), прохідний — 24. Питання й відповіді лежать тільки на сервері: `lib/exam.js`.
- Сертифікат видається лише учням (відкрили іспит через бота в Telegram і є в групі ARBI SCHOOL). У браузері іспит пройти можна, але без сертифіката.
- Сертифікат — PNG з номером `AX-РРММДД-XXXXXXXX`. Кнопка «Надіслати в бот» шле файл учню в чат з ботом. Куратори отримують повідомлення в групу підтримки.
- Перевірка: вкладка 🎓 → «Перевірити сертифікат» (номер + імʼя).
- **Нова змінна у Vercel:** `CERT_SECRET` — будь-який довгий випадковий рядок. Не змінюй його потім, інакше старі сертифікати перестануть перевірятись.
- Щоб дозволити сертифікат без Telegram (наприклад для тесту): `EXAM_OPEN=1`.

### Умови і відповідальність
Вкладка ⚖️ (посилання внизу апки) + кнопка «⚖️ Правила і відповідальність» у боті. Текст — `assets/data.js` → `ARBI.TERMS` і `support.json` → `disclaimer`.

### Кнопки навігації в гілках
- Гілки і тексти — `lib/nav-config.js` (ID гілок уже прописані).
- Бот має бути **адміном** групи ARBI SCHOOL з правом **закріплювати повідомлення**.
- Запуск (один раз): `https://arbix-tools.vercel.app/api/nav?key=<CRON_SECRET>` — бот опублікує і закріпить навігацію в усіх 15 гілках (~30 с).
- Попередній перегляд без відправки: додай `&dry=1`.
- У відповіді буде `editUrl` — **збережи його**. Якщо потім зміниш тексти/кнопки в `lib/nav-config.js`, задеплой і відкрий `editUrl`: бот оновить старі повідомлення, без дублів.
- Нова гілка: додай її в `lib/nav-config.js` і запусти з `&only=<id гілки>`.
